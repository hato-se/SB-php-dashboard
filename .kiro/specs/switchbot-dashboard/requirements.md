# 要件定義 — SwitchBot PHP ダッシュボード

## 概要

SwitchBot 温湿度計（Meter 系デバイス）のリアルタイムデータを
SwitchBot OpenAPI v1.1 経由で取得し、ブラウザ上のシンプルな
PHP ダッシュボードに表示する個人向け Web アプリケーション。

---

## 機能要件

### FR-01: 認証・設定管理

- **FR-01-1** アプリは SwitchBot の Open Token と Secret Key を `config.php` ファイルから読み込まなければならない
- **FR-01-2** リクエストごとに HMAC-SHA256 署名（`sign`）、13桁タイムスタンプ（`t`）、UUID v4（`nonce`）を生成しなければならない
- **FR-01-3** 認証情報はソースコードにハードコードしてはならない
- **FR-01-4** `config.php` はユーザーが FTP クライアント等でアップロードし、テキストエディタで値を書き換えるだけで設定できること
- **FR-01-5** `config.php` への直接 HTTP アクセスは `.htaccess` によって拒否しなければならない

### FR-02: デバイス一覧取得

- **FR-02-1** ダッシュボード初期表示時に `GET /v1.1/devices` を呼び出し、アカウントに登録された物理デバイスの一覧を取得できること
- **FR-02-2** 取得したデバイスのうち、`deviceType` が `Meter` / `MeterPlus` / `MeterPro` / `WoIOSensor`（Outdoor Meter）に該当するものをフィルタリングして表示すること
- **FR-02-3** 温湿度計が 1 台も見つからない場合は、ユーザーに分かりやすいメッセージを表示すること

### FR-03: 温湿度データ取得・表示

- **FR-03-1** 各温湿度計デバイスに対して `GET /v1.1/devices/{deviceId}/status` を呼び出し、最新の温度・湿度を取得できること
- **FR-03-2** 取得した温度（`temperature`）を摂氏（℃）で表示すること
- **FR-03-3** 取得した湿度（`humidity`）をパーセント（%）で表示すること
- **FR-03-4** デバイス名（`deviceName`）をカードのタイトルとして表示すること
- **FR-03-5** データ取得日時（サーバー側のタイムスタンプ）を表示すること

### FR-04: 手動更新

- **FR-04-1** ユーザーが「更新」ボタンをクリックすると、ページをリロードせずに最新データを再取得できること（Ajax / fetch API）
- **FR-04-2** データ取得中はローディングインジケータを表示すること

### FR-05: エラーハンドリング

- **FR-05-1** API が HTTP 401 を返した場合、「認証エラー: トークンを確認してください」とメッセージを表示すること
- **FR-05-2** API が statusCode 190（デバイスオフライン）を返した場合、対象デバイスを「オフライン」として表示すること
- **FR-05-3** cURL 通信エラー時は技術的な詳細をサーバーログに記録し、ユーザーには汎用エラーメッセージを表示すること
- **FR-05-4** 1日の API 呼び出し上限（10,000 回）超過時は適切なメッセージを表示すること

## 非機能要件

### NFR-01: セキュリティ

- **NFR-01-1** `config.php` は `.gitignore` に含め、リポジトリにコミットしないこと
- **NFR-01-2** `config.php` への直接 HTTP アクセスは `.htaccess` の `Deny from all` で遮断すること
- **NFR-01-3** PHP の `display_errors` は本番環境で `Off` にすること
- **NFR-01-4** 本番環境では HTTPS を使用すること
- **NFR-01-5** ダッシュボードへのアクセスに HTTP Basic 認証または IP 制限を設けることを推奨する（必須ではない）

### NFR-02: パフォーマンス

- **NFR-02-1** API レスポンスをサーバーサイドで最低 60 秒間キャッシュし、不要な API コールを削減すること
- **NFR-02-2** ダッシュボードの初期表示は 3 秒以内を目標とする

### NFR-03: デプロイ・運用

- **NFR-03-1** SSH アクセスなしで運用できること（FTP/SFTP によるファイルアップロードのみ）
- **NFR-03-2** `composer` コマンドを実行せずに動作すること（オートローダーは `require` ベースで自前実装）
- **NFR-03-3** 設定変更は `config.php` の定数値を書き換えてアップロードするだけで完了すること
- **NFR-03-4** すべてのファイルをレンタルサーバーの公開領域（`public_html/` 等）に配置できること
- **NFR-03-5** キャッシュファイルの保存先はサーバー上の書き込み可能なディレクトリを `config.php` で指定できること

### NFR-04: 保守性

- **NFR-04-1** PSR-12 コーディング規約に準拠すること
- **NFR-04-2** API クライアント・認証・設定の各クラスは単一責任の原則に従って分離すること
- **NFR-04-3** PHP 8.1 以上で動作すること

### NFR-05: ユーザビリティ

- **NFR-05-1** レスポンシブデザインに対応し、モバイルブラウザでも閲覧できること
- **NFR-05-2** 温度・湿度の値は視認性の高いフォントサイズで表示すること

---

## 制約

- SwitchBot OpenAPI は個人利用のみ。商用利用には別途申請が必要
- API コール上限: 1日 10,000 回
- **SSH アクセス不可のレンタルサーバーを対象とする（FTP/SFTP でのファイル転送のみ）**
- **`composer` コマンドを使用しない（サーバー上での CLI 実行不可のため）**
- 外部 PHP フレームワーク（Laravel 等）は使用しない（依存関係を最小化する）
- JavaScript フレームワーク（React 等）は使用しない
